## Hybrid Layer Types
LFM2.5 uses a `layer_types` array that alternates between three layer variants:
- `"conv"`: Mamba2 convolutional block (SSM linear attention)
- `"full_attention"`: Standard multi-head self-attention

The layer pattern repeats every 5 layers: `["conv", "conv", "full_attention", "conv", "conv"]`

## Architecture Features
- **Dense**: 2.6B parameters, no MoE
- **Hybrid**: Mixes Mamba2 conv layers with full attention layers
- **Agentic**: Optimized for agentic workloads (tool calling, coding, multi-step tasks)
- **On-device**: Small enough to run on phones/laptops
- **128K context**: Extended for agent memory
